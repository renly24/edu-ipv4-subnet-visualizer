# IPv4 ネットワーク部・ホスト部 見える化（教育用）

IPv4 アドレスとサブネットマスクを入れると、**どこまでがネットワーク部で、どこからがホスト部か** を色分けして表示する Web アプリです。

## 内容

### 🧭 見える化

1. **アドレスとサブネットマスクを入れる**
   - IPアドレス（`192.168.1.10/24` のように CIDR 表記でも可）とサブネットマスク（`255.255.255.192` など）を入力
   - スライダーで /0〜/32 を動かすと、色分けがその場で変わる
   - 例ボタン：/24・/16・/8・/26・/28・/30
2. **ネットワーク部とホスト部を見る**
   - 10進数のアドレスと32ビットの2進数を、ネットワーク部（青）・ホスト部（オレンジ）で色分け。赤い線が境目
   - ビットをクリックすると、そこまでがネットワーク部になる
   - 境目がオクテットの途中にあるとき（/26 など）は、そのオクテットを重み（128〜1）つきで拡大し、10進数の値がどう分かれるかを表示
3. **このネットワークについて**：ネットワークアドレス・ブロードキャストアドレス・割り当てられる範囲・機器の数、入力したアドレスの役割
4. **計算のしかた（AND）**：IPアドレスとサブネットマスクの論理積でネットワークアドレスを求める様子
5. **しくみ**：ネットワーク部とホスト部、サブネットマスクの読み方などの解説

### ✏️ 練習問題（1セット10問）

| レベル | 出題 | 答え方 |
| --- | --- | --- |
| 1：境目をさがす | IPアドレスとサブネットマスク（10進数） | 2進数のビットをクリックして、ネットワーク部の最後のビットを選ぶ |
| 2：ネットワークアドレス | IPアドレスとサブネットマスク | ホスト部をすべて0にしたアドレスを入力 |
| 3：ブロードキャストアドレス | IPアドレスとサブネットマスク | ホスト部をすべて1にしたアドレスを入力 |

- 問題は毎回ランダムに作られます（/26 のようにオクテットの途中で分かれるものが中心）
- 「ヒント」でマスクの2進数や色分けを表示、答え合わせ後は色分け・境目のオクテットの拡大・AND の計算で解説
- 結果画面（正解数・ヒント使用数・日時・全問の見直し）はスクリーンショットで提出する想定です（結果はサーバに保存されません）

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-ipv4-subnet-visualizer/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-ipv4-subnet-visualizer/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります（edu-network-simulator と同じ値）。
